## 外部调研自动化方向

- **API 自动化不接受**：会丢失各平台网页端的数据差异性（社区检索、登录态、账号数据源）；
- 探索**浏览器自动化**：自定义 Chrome 扩展 + 本地桥（127.0.0.1 WebSocket/native messaging）
  + Agent 侧 runner，操作用户已登录的 Chrome 标签页；
- 风险：DOM 变更、平台 ToS/风控、桥安全（白名单 + 本地 token + 人工确认模式）；
- 计划：P1 单平台原型（ChatGPT）→ P2 多平台适配 → P3 安全打磨（未开始）。
