# 过程记录（Notes）

> 状态: ACTIVE · 最后更新: 2026-08-12

存放功能讨论、方向探讨、调研、头脑风暴、会议等**过程性**内容。
规则见 [docs/DOCUMENTATION_GUIDE.md](../DOCUMENTATION_GUIDE.md#3-过程记录notes)。

## 命名

**大小分流**：

- 大型主题：`YYYY-MM-DD-短slug.md`（一次实质讨论/调研一个文件）；
- 细碎信息：`YYYY-MM-DD-note.md`（当日汇总，每条带小标题）。

示例：`2026-08-12-docs-management.md`（大主题）、`2026-08-12-note.md`（当日细碎记录）。

## 每日笔记（YYYY-MM-DD-note.md）格式

```markdown
# YYYY-MM-DD 工作记录

## 小主题 1
一句话结论/记录

## 小主题 2
一句话结论/记录

（某主题累积到值得展开时，拆成独立文件 YYYY-MM-DD-短slug.md）
```

## 模板

```markdown
# YYYY-MM-DD: 主题

> 类型: 讨论 | 调研 | 头脑风暴 | 会议
> 日期: YYYY-MM-DD
> 参与: （可选）
> 关联: ADR-xxxx / MR-xxx / 其他笔记（可选）

## 背景

## 讨论要点 / 调研发现

## 结论

（无结论就写"暂无结论"）

## 下一步

（无下一步就写"暂无"）

## 未决问题
```

## 约定

- 内容可以粗糙，骨架必须完整；"结论/下一步/未决问题"三节必须存在；
- 大型主题走完整模板；每日笔记允许极简，但每条要有小标题方便检索；
- 写完不删除、不改写；新进展开新篇并互相引用；
- 产生方向性取舍时，在 notes 基础上另写 ADR（notes 是过程，ADR 是决策）。
