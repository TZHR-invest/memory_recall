# 02 · round-01 提示词（全平台同题，开放无预设）

> 执行方：codex 操作浏览器，把下面的文本块整块复制粘贴到对应平台，回答原文回填到
> `03-round-01-answers-<platform>.md`（一个平台一个文件，不二次概括）。

## 说明

本轮不拆分问题：**同一个开放问题发给全部平台（ChatGPT / Claude / Grok / Gemini / doubao）**，
靠各平台自身视角的差异来获得更完整的答案。提示词不点名任何文献 / 框架，不预给价值定义，
不预设答案形态。

## 同一题（发给全部平台）

```text
背景：我们在做一个 AI 开发助手。它会陪伴用户开发项目，并在这个过程中持续接触、记录大量信息——
用户说过的话、项目产出的内容、项目的现状与规划、开发环境配置、踩坑与修复过程等等。

这些信息里，绝大多数是「当下这一次、具体的」，用过就过去了；但其中有一部分，用户希望以后还能
用得上——也许是这个项目稍后还要用，也许是以后做别的项目时也能用。

我们目前对下面这件事没有既定答案，想听你从自己的知识体系和经验出发，给出你认为最本质、也最完整
的看法：

系统应该依据什么来判断「哪些信息值得被长期沉淀下来」，以及这些值得沉淀的信息，应该以什么形态、
通过怎样的过程被留存，才能在将来真正需要时被有效复用？

请你自由组织回答，不必受任何特定框架的限制；如果你认为这个问题本身问偏了，也请直接指出。
关于出处请尽量诚实：来自具体文献 / 实践的请给出处；是你自己推理 / 综合的请标明是推理；不确定的
请直说不知道。
```
