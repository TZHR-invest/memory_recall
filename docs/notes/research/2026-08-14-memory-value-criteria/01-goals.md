# 01 · 背景、锚点、已知事实与研究问题

> 归属: [README](README.md) 调研卡 · 日期: 2026-08-14

## 背景（为什么做这个调研）

产品已重定位为「命题成熟度引擎」，覆盖 记忆 → 个人知识 → 团队知识，灵魂是"提炼"（把具体记录变成可复用知识）。
但"什么时候该提炼、一条记录凭什么值得晋升"没有判据——这是 S0+S1 的第一刀，也是最核心的一刀。

讨论中发现：从零发明判据风险高，而这个问题在四个领域都有成熟研究。故先做外部调研，把"已验证的判据"偷回来，
再决定我们自己的规则集。**调研问的是判据，不是分类法**（分类法对我们无用，之前已被叫停）。

## 锚点（价值定义，勿偏离）

- 场景：agent 做项目开发，很多用户已知的信息不应重复输入；
- 记忆对象：项目产生的信息、用户输入、项目现状 / 规划设计、开发环境等，甚至跨项目复用的项目无关知识；
- **价值 = 未来还会被需要，且忘记会导致重复成本（用户重新输入 / agent 重新查·推）**；
- 两层范围：项目内 + 跨项目（项目无关、可迁移）。

## 已知源码事实（调研结论要映射回这些落点）

- `memories` 表已有 `confidence FLOAT DEFAULT 0.8`（当前未用作模型——未来晋升信号的候选落点）；
- `is_static`（性质分类）/ `is_latest`（取代降级）/ `is_inference`（推理标记）三标志并存；
- `memory_relations` 已有 `updates / extends / derives` 关系；`create_derived_memory` 已实现"派生记忆"
  （`is_inference=TRUE` + `derives` 边），现用于实体关系推断；
- `container_tag = {keyId} | {keyId}_project-<dir>`（归属 × 项目的隐式编码）；
- `memory_profiles` 画像缓存是第三套生命周期（MR-008 教训：多套生命周期会打架）；
- 6 维命题模型：内在（内容 / 适用条件 / 置信度 / 时效 / 泛化性）+ 系统（归属 / 载体）。

## 现有假设（待调研验证，勿当结论）

讨论中预判文献会收敛到这几个候选判据，调研负责补漏 / 证伪 / 排序：

1. 跨上下文复现（同一件事在多个无关场景重复出现）；
2. 被纠正 / 冲突（它推翻了一个旧认识）；
3. 复用频率（被真的查出来用过多少次）；
4. 再获取成本（忘了之后重新搞清楚的代价）；
5. 时效稳定性（以后还成不成立）；
6. 能说清适用条件（讲不清"什么时候成立"就不安全）。

## 研究问题清单（每问都已过"会改变决策吗"筛，均为 C 类·文献/信息差）

### Q1 判据本体（核心）
- **问**：在 agent 记忆 / 认知科学 / 知识管理里，"一条信息值得保留或晋升为知识"的判据有哪些？各自怎么操作化？
- **查**：认知科学记忆巩固；agent 记忆（generative agents 反思、MemGPT、记忆蒸馏 / 反射）；PKM
  （Forte 捕获标准、Zettelkasten 原子笔记、渐进式摘要）；组织知识（DIKW、SECI）。
- **产出**：候选判据列表，每条"名称 + 谁提出 + 怎么操作化（能否变信号 / 阈值）+ 证据"。
- **改决策**：我们的晋升规则集从哪些判据里选。

### Q2 项目内 vs 跨项目
- **问**：怎么识别"项目无关、可跨项目复用"的知识？它和项目内知识的判据是否不同？
- **查**：agent 记忆的全局 vs 项目级划分；知识可迁移性；"上下文依赖 / 适用条件"概念。
- **产出**：区分两类的识别信号（尤其：判据是否引用"本项目 / 当前环境"）。
- **改决策**：6 维里"归属 / 载体"如何按项目内 / 跨项目分流。

### Q3 价值度量（最贴锚点）
- **问**："重复输入 / 再获取成本"作为记忆价值度量，文献有没有可操作近似？
- **查**：PKM 捕获实用标准（Forte resonance / capture 清单）；认知里的再获取成本；agent 记忆的
  "未来引用概率"估计。
- **产出**：把"值得记"变成可估计信号的方法（复用频率 / 再获取时间 / 被再次需要概率）。
- **改决策**：用什么信号驱动保留 / 晋升（confidence 之外的新信号）。

### Q4 晋升 / 抽象时点（灵魂）
- **问**：文献怎么处理"具体经历 → 通用知识"的转化？什么时候抽象、什么时候保留原始记录？
- **查**：认知科学 episodic→semantic（Tulving）；generative agents 的 reflection / abstraction；记忆蒸馏。
- **产出**：抽象 / 晋升的触发判据 + "什么不该抽象"。
- **改决策**："质变"的定义与触发（提炼心脏）。

### Q5 负例 / 污染（安全阀）
- **问**：有没有研究"记了反而有害"（错误泛化、过时知识误导、记忆污染）？怎么防？
- **查**：agent 记忆的幻觉 / 过时知识问题；PKM 的"不做什么"；认知里的错误记忆。
- **产出**：晋升的安全阀（如"适用条件必须显式"）。
- **改决策**：晋升 gating 与"记忆不反向污染知识库"规则。
