# ADR-0011: 北极星 = 价值公式（状态有效性降级为因子）

> 状态: Accepted
> 日期: 2026-08-14
> 关联: [目标模型 v1](../designs/target-model/v1.md) · [命题晋升总纲](../notes/2026-08-14-proposition-promotion.md) ·
> [价值判据 v2 调研](../notes/research/2026-08-14-memory-value-criteria-v2/99-final-conclusions.md) ·
> [复用反馈回收 Q2 调研](../notes/research/2026-08-14-reuse-feedback-signals/99-final-conclusions.md)

## 背景

系统需要一个唯一判据，来裁决"记住什么 / 召回什么 / 保留什么 / 晋升什么"。候选判据来自三路输入：
检索命中率（v2 之前隐含）、状态有效性（状态有效性 thread）、复用价值（v2/Q2）。需要定一个北极星，
避免多个判据互相打架。

## 选项

- A: **检索命中率 / 召回精度**作为北极星——错召回不算命中，但"正确召回却内容过时"仍会误导，管不到内容质量。
- B: **状态有效性**作为北极星——"这条现在还成立吗"，但它回答的是"对不对"，是手段不是目的。
- C: **价值公式**作为北极星——复用机会 × 有效性 × 影响 − 维护/遗忘成本，错误信息按负价值计。

## 决策

选 **C**。北极星 = 价值公式；**错误信息按负价值计，且权重高于"缺信息"（无信息 > 错误信息）**。
"状态有效性"降级为价值公式里"有效性"因子的度量手段（+ 错误信息的惩罚项）。

## 理由

- 召回精度只回答"找得准不准"，状态有效性只回答"内容对不对"，二者都是价值公式的**因子**，不是目标本身；
  价值公式直接对应"值不值得留/召回"这个真实问题。
- 价值公式是**排序启发式**而非精确计算；"分解后再估"（P/C 分开估）优于直接估乘积（promotion-judgment 已定）。

## 后果

- 正面：后续所有生命周期 / 召回 / 晋升 / 遗忘决策有唯一裁判。
- 负面：价值公式里"有效性 × 影响"最难观测（反事实），须靠 S-pre 遥测（复用标注）才能算得动——
  这反向确立了遥测的必要性。
- 跟进：错误惩罚的权重如何落地（Beta-Bernoulli 权重 / 证据加权表），留 S2 置信度细化。
