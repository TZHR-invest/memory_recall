# ADR-0006: 会话摘要不写入记忆库

> 状态: Accepted
> 日期: 2026-08-12
> 系统: v5
> 关联: ADR-0008

## 背景

曾计划把 opencode 压缩生成的会话摘要写入记忆库（带 `[会话摘要]` 前缀），用于跨会话追忆。
实际评估：会话摘要是"某次会话的状态快照"，不是长期知识；写入记忆库会污染语义召回，
与"事实/偏好/决策"混在一起。代码中 `src/summary.ts` 的 `SummaryCapture` 类全仓无引用，是死代码。

## 选项

- A: 写入记忆库（带前缀 + 过滤）；
- B: 不写入记忆库，仅内存缓存；
- C: 不写入也不缓存（缓存问题见 ADR-0008）。

## 决策

选择 **B 的方向并固化为数据边界**：会话摘要永不写入记忆库；
删除 `src/summary.ts` 死代码。缓存与捕获机制的存废由 ADR-0008 决定。

## 理由

- 摘要不是知识：它是会话状态，进入记忆库会稀释事实召回质量；
- 代码已实现"不写入"（`saveSummaryAsMemory` 返回 null），本文档固化该行为；
- 死代码必须清理，避免后续 Agent 误以为可复用。

## 后果

- 正面：记忆库保持知识纯净；无前缀过滤逻辑；
- 负面：没有跨会话摘要追忆能力；
- 跟进：若未来需要"会话状态"跨会话保留，需新 ADR 并单独设计对象，不复用记忆库。
