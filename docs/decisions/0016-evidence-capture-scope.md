# ADR-0016: Evidence 采集范围分四档（含"不做"清单）

> 状态: Accepted
> 日期: 2026-08-14
> 系统: crystal
> 关联: [目标模型 v1](../designs/target-model/v1.md) · [插件信号面盘点](../notes/research/2026-08-14-reuse-feedback-signals/10-plugin-signal-surface.md) ·
> MR-019 · ADR-0010 · ADR-0012

## 背景

ADR-0012 定了 Evidence 是不可再生地基，但没定**采什么**。采集范围决定两件事：不可再生资产会不会漏采
（漏采=永久丢失）、会不会爆量（噪音淹没对账）。候选来源从便宜到昂贵差异极大，需要定边界与优先级。

## 选项

- A: **全量采集**——把 agent 生命周期所有输入（含整个上下文）都当 Evidence。
- B: **分档采集 P0–P3**——按"信号价值 × 采集成本 × 是否真不可再生"分四档，逐档推进。
- C: **只采 add 自报**——最小闭环，其余都不采。

## 决策

选 **B**，四档：

| 档 | 来源 | 判定 |
|----|------|------|
| **P0 必做（已在）** | add 接口自报（agent 显式想记的） | 最便宜、意图最高，是地基 |
| **P1 下一步** | 召回后结果上报 | **主要不是 Evidence，是复用标注**（喂 `reuse_confidence`）；其中"结果痕迹"（diff/测试/退出码）将来可升格"结果类 Evidence" |
| **P2 有条件** | 项目文档读取蒸馏 | 仅 opencode/dsh 能被动采，MCP 端采不到；与 MR-019 纠缠、ADR-0010 刚移出文档 → **挂起等解冻** |
| **P3 不做** | 整个上下文理解 | 99% 是过程噪音、违背"agent 自报优先"、贵且低质 |

补充两点：

- **P0 是内容轴的地基，P1 才是让北极星（价值公式）算得动的输入**（它喂最难观测的"有效性×影响"）。
- **"理解整个上下文" ≠ "存原文 dump"**：理解（LLM 蒸馏）现在不做；存原文（append-only dump 供将来重算）
  符合 Evidence 不可再生原则，但存储成本需单独评估，也不现在拍板。

## 理由

- 否决 A：全量采集把 99% 的过程噪音也当不可再生资产，存储爆掉、对账被噪音淹没，且违背"agent 自报优先"
  （agent 已通过 add 告诉你什么值得记，系统不该无视这个信号重读全部）。
- 否决 C：只采 add 自报没有复用/结果信号，价值公式的"有效性×影响"永远算不动（ADR-0011 的北极星落空）。
- B 逐档推进：高价值、低成本、可逆的先做；低价值、高成本、需宿主扩展的挂起或不做。

## 后果

- 正面：采集有明确边界与优先级，不可再生资产不会因"什么都想采"而漏掉关键源，也不会被噪音淹没。
- 负面：P1 的结果上报依赖插件信号面（仅 opencode/dsh 可被动采 outcome）；P2 文档蒸馏冻结在 MR-019。
- 跟进：P1 复用标注的具体字段与回传通道（挂 S-pre 阶段 1）；"存原文 dump"的存储成本评估。
