# MR-006: 无统一"知识对象/单一事实源"，最新语义多路径不一致

> 状态: OPEN · 严重度: P0 · 创建: 2026-08-12

## 问题

记忆的两种取代语义并存：自动关系检测只降级 `is_latest=FALSE` 不建版本链，产生大量
`version=1, root_memory_id=NULL` 的孤儿旧版本（主容器实测 937 行）；显式 update 才建链。
搜索过滤 `is_latest`，但记忆图谱扩展和 `get_by_id` 不过滤——"什么是最新的"在三条召回路径上
答案不一致。画像缓存（`memory_profiles`）是第三套生命周期，一致性靠调度补丁
（曾出现 1970 哨兵时间戳问题）。

## 建议

把"知识对象"（一个事实的当前状态 + 来源 + 时间 + 置信度）作为一等概念；
短期内至少统一 `is_latest` 在全部召回路径上的过滤规则。
