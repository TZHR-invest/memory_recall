# MR-011: 缺少知识浏览/纠错闭环

> 状态: OPEN · 严重度: P0 · 创建: 2026-08-12

## 问题

用户无法查看"系统记住了什么"并修正它：dashboard 只有统计数字，没有记忆/文档/实体浏览与搜索页，
没有图谱可视化页，forget/update 只有 API 没有界面。对记忆产品，可见性 + 可纠正是信任闭环的核心。

## 建议

做一个最小知识浏览页（列表/搜索/实体下钻 + 编辑/删除入口），复用现有 API。
