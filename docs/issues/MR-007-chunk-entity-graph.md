# MR-007: 文档知识只有向量路，实体图谱关联浅

> 状态: 已关闭（ADR-0010） · 严重度: P1 · 创建: 2026-08-12 · 关闭: 2026-08-13

## 问题

`chunk_entities` 的实体来自**文档摘要**（截断 4000 字）的 NER，然后按"实体名是否出现在
chunk 文本"做字符串匹配映射（`document_store._extract_and_map_entities_to_chunks`）。
摘要之外的实体、非字面匹配的关联全部丢失，文档基本只能靠向量相似度召回。

## 建议

chunk 级实体/关系提取，或文档级知识摘要直接入库为可图遍历的知识节点。
