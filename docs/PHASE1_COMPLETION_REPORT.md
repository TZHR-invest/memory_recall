## 一、项目概述

Memory Recall 是一个通用的记忆召回系统，旨在解决人类记忆痛点（时间追溯、事件召回、位置记忆、灵感捕捉），同时服务于 AI Agent 的上下文管理需求。

**核心目标**：
1. 首先解决人类记忆痛点
2. 其次服务 AI Agent 上下文窗口有限的问题

## 五、部署说明

### 5.1 环境要求

- Python 3.10+
- PostgreSQL 14+ (with pgvector)
- Docker & Docker Compose (推荐)
- 火山引擎 API Key

### 5.2 快速部署

#### 方式 1: Docker Compose（推荐）

```bash
# 1. 克隆项目
git clone https://github.com/TZHR-invest/memory_recall.git
cd memory_recall

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 文件，填入 VOLC_API_KEY

# 3. 启动服务
docker-compose up -d

# 4. 初始化数据库
docker-compose exec api python scripts/init_db.py

# 5. 访问服务
# API: http://localhost:8000
# 前端: http://localhost:3000
```

#### 方式 2: 本地开发

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动数据库
docker-compose up -d postgres

# 3. 初始化数据库
python scripts/init_db.py

# 4. 启动 API 服务
uvicorn main:app --reload --port 8000

# 5. 启动前端（另一个终端）
cd web && python3 -m http.server 3000
```

### 5.3 环境变量

```bash
# 数据库配置
DATABASE_URL=postgresql://memory_recall:password@localhost:5432/memory_recall

# 火山引擎配置
VOLC_API_KEY=your_api_key_here

# 其他配置
LOG_LEVEL=INFO
ENVIRONMENT=development
```
