## 🚀 性能优化

### LLM 调用优化

**优化前**：场景判断（1 次）+ 实体提取（1 次）= 2 次 LLM 调用  
**优化后**：场景判断 + 实体提取（1 次）= 1 次 LLM 调用  
**优化效果**：减少 50% LLM 调用，降低延迟

### 1. 场景类型

- `daily_chat`：日常对话，关注人物、地点、偏好、情绪
- `work_meeting`：工作会议，关注事件、时间、任务、决策
- `diary`：日记，关注事件、感受、时间、地点
