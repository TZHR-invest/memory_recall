### 遇到的问题及解决方案

#### 问题 1：向量存储格式错误

**错误**：`expected str, got list`

**原因**：PostgreSQL 的 vector 类型需要字符串格式的向量数据

**解决方案**：
```python
# 将向量列表转换为字符串格式
embedding_str = "[" + ",".join(map(str, embedding)) + "]"
```

#### 问题 2：Pydantic 模型验证错误

**错误**：`PersonInfo.name` 不能为 None

**原因**：PersonInfo 模型的 name 字段是必填的

**解决方案**：在构建 PersonInfo 时，过滤掉没有 name 的数据

**遇到的问题及解决方案**：

1. **数据库版本不兼容**
   - 错误：PostgreSQL 14 与现有数据不兼容
   - 解决：更新为 PostgreSQL 16

2. **数据库密码不匹配**
   - 错误：docker-compose.yml 和 .env 文件密码不一致
   - 解决：统一为 "postgres"

3. **数据库表缺少列**
   - 错误：缺少 `input_type`、`access_count` 等列
   - 解决：执行 ALTER TABLE 添加所有缺失的列

4. **ID 格式不匹配**
   - 错误：UUID 类型与字符串类型不匹配
   - 解决：在 `_row_to_memory` 方法中将 UUID 转换为字符串

5. **向量维度不匹配**
   - 错误：数据库 768 维，实际生成 1024 维
   - 解决：修改数据库表为 1024 维

6. **代码重复导入**
   - 错误：UnboundLocalError 在 lifespan 函数中
   - 解决：删除重复的 `from src.database import db`
